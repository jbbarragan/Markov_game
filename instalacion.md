# Ejecución local
Extrae el proyecto y ejecuta `python run_local.py` o `INICIAR_JUEGO.bat`. El servidor local usa Python nativo, sin descargas externas. Abre una sola pestaña por servidor. Para GitHub Pages consulta README.md; la versión publicada utiliza el Pyodide incluido en game-v5/vendor/pyodide.
